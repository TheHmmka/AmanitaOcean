## Signal path

```
48 kHz in -> converter -> [ 44 samples -> 8 + 8 modulated lines -> fixed filter ] -> converter -> 48 kHz out
                            44.1 kHz core, feedback inside each group of 8
```

### 1. The core runs at 44.1 kHz (README item 7 resolved)

- MEASURED. The high-frequency gain of an isolated arrival at 48 kHz follows the
  fractional part of its position counted in 44.1 kHz samples: a scan of the
  assumed internal rate from 20 to 200 kHz has one minimum, at 44100 Hz
  (unexplained variance 9.8 % with a first-harmonic model; no rate more than
  400 Hz away gets below 86 %, the median is 99.9 %). Linear interpolation is
  done on the internal grid, so the fraction at 48 kHz is the wrong variable.
- MEASURED. With the host at 44.1 kHz there is no conversion: the response is
  exactly zero before the first arrival, there is no pre-ringing, and every
  arrival is two adjacent samples followed by one fixed causal filter.
  The 44.1 kHz host is therefore a microscope for the core; stage 1 of the fit
  uses it.

### 2. Lines

- MEASURED. Sixteen lines in two groups of eight, one group per output. A raw
  arrival at 44.1 kHz sits at `88 + length`; 44 of the 88 samples are the
  reported latency.
- FITTED, integer within 7e-5 samples for 14 lines. Centre lengths are primes:
  L group 1031, 1097, 1187, 1289, 1423, 1583, 1783, 2027;
  R group 1039, 1109, 1193, 1301, 1429, 1597, 1787, 2039.
- FITTED. Modulation depth 38.80800 to 38.80802 internal samples on all 14
  fitted lines: **0.88 ms exactly** (0.88e-3 x 44100 = 38.808). Using 38.814,
  the value a pure-sine fit returns, costs 28 dB (validation -43.5 dB).
- MEASURED. Read rule: linear interpolation, `weight(n) = max(0, 1 - |n - length(n)|)`,
  with the length taken at the read sample. The sum of the two weights is
  `1 + c x slope` with c = 1.003 to 1.024 over 14 lines; a moving read pointer
  gives c = 1 (the 1.6 % mean excess is not explained).
  Position residual of the law: 5e-5 samples rms, 2e-4 max, per line.
- FITTED. The fixed filter comes after the lines (two taps convolved with the
  filter null at -71 dB). The form with the filter before the lines reached
  only -38.5 dB in one test; that implementation was not cross-checked.

### 3. Modulation law: a float32 phase accumulator

A pure sinusoid does not fit: 0.019 samples rms remain, with kinks at fixed
phases. The law that fits is

```
theta[n+1] = fl32(theta[n] + fl32(2 pi 0.6 / 44100));  if theta >= 2 pi: theta -= 2 pi
length[n]  = prime + 38.808 sin(theta[n])
```

- MEASURED. The kinks of the deviation sit at 0, 0.32 and 0.63 cycle, which are
  0, 2 and 4 rad: the binade edges of a float32 phase in radians. Inside
  [2, 4) the rounded increment is 0.125 % high, inside [4, 2 pi) 0.154 % low.
- MEASURED. The emulated cycles last 73514 or 73515 samples (mean 73514.75
  over four cycles); the measured mean rate is 0.599878 Hz (period 73514.95).
  The nominal rate is 0.6 Hz (period 73500); the README's 0.59988 Hz is the
  average of this accumulator.
- FITTED. One accumulator per line (the kinks follow each line's own phase).
  With the emulation the position residual drops from 0.019 to 5e-5 samples.
- FITTED. Start phases at the first processed sample, order L1, R1, L2, R2, ...:
  0.0000003, 4.966815, 3.650443, 2.334072, 1.017701, 5.984517, 4.668146,
  3.351764, 2.035385, 0.719012, 5.685821, 4.369442, 3.053066, 1.736698,
  0.420338, 5.387163 rad. Line L1 starts at 0 within 1e-6 rad. They follow
  `k x 4.966812 rad` (0.790493 cycle; 0.5810 cycle between lines of one group,
  the README's step) within 2.1e-5 rad.
  Round-value test: using `k x 4.966812` costs 5 dB (validation -66.4 dB), so
  the data file keeps the sixteen fitted values. OPEN: the rule behind them.
  Tested and rejected (best 1.4e-5 rad): exact multiples, float32 products,
  float32 accumulation with and without wrapping, a pre-run of up to 27 s.
- MEASURED. **Time origin: the start of processing, warm-up included.** A
  capture with a 7 s warm-up scores -71.47 dB when the model's clocks start
  7 s before the stimulus and +2.9 dB when they are left at 10 s. The phase
  does not depend on the host block (README item 2: bit-identical for five
  block sizes). Consequence for the product: the phase of the Character's
  modulation is defined by the sample count since reset.

### 5. The scored window is not first-pass only

- MEASURED. With the eight lines of each group removed, raw [2060, 2198) at
  44.1 kHz (48 kHz raw 2350 to 2500) still holds -25 dB of the window energy.
  At 48 kHz the model without second passes scores -25.4 dB on validation.
  The statement in `score_first_order.py` that the window holds first passes
  only does not hold: the 88 internal samples and the converter delays are not
  doubled on the second pass.
- MEASURED. The extra arrivals are line i feeding line j **of the same group**,
  arriving at `88 + length_i(first read) + length_j(second read)` with no extra
  sample in the feedback path (one extra sample: fit fails, -0.9 dB). No
  arrival exists at a position that would need a line of the other group.
  Six ordered pairs per group reach the window: 1->1, 1->2, 2->1, 2->2, 1->3, 3->1.
- FITTED. Pair gains, L group: 0.0078447, 0.0105889, -0.0065864, 0.0088898,
  0.0113338, -0.0057210; R group: 0.0078058, 0.0105227, -0.0065453, 0.0088237,
  0.0112847, -0.0056966. The cross-input ratio is again 0.5723 (0.57231 to
  0.57234), so the cross feed is at the input of the lines.
- INFERRED from those twelve numbers. Writing a pair gain as
  `input_i x decay_i x M_ji x decay_j x output_j`, every available combination
  gives the same feedback magnitude: `M_11`, `M_22`, `sqrt|M_12 M_21|` and
  `sqrt|M_13 M_31|` are 0.24791 to 0.24794 in both groups, with `M_12 M_21`
  and `M_13 M_31` negative. That is the signature of a feedback matrix whose
  entries all have one magnitude (a Hadamard-type matrix scaled to 1/4 would
  give 0.25; 0.2479 is 0.8 % lower). Only 6 of 64 entries per group are seen.
- FITTED. The fixed filter acts once on a second pass (twice: fit fails), so it
  is outside the loop. The second pass carries a short kernel of its own:
  0.99939 at lag 0, then a negative tail from lag 2 (-0.0040, -0.0019, -0.0030,
  -0.0018, ...), DC gain 0.9766, Nyquist gain 0.9944, 40 taps stored, one
  kernel for both groups. With a pure gain the second passes are modelled to
  -42.5 dB of their own energy, with the kernel to -54 dB.

### 6. Fixed filter

FITTED as 960 taps at 44.1 kHz (stage 1). First taps 1, 0.3095, -0.3043,
0.2516, -0.1938, 0.1497, -0.0854: ringing near the internal Nyquist frequency.
Gain relative to 1 kHz: +0.3 dB at 0 Hz, +0.76 dB at 200 Hz, +0.6 dB at 15 kHz,
+1.5 dB at 19 kHz, -3.4 dB at 20.5 kHz, -10.5 dB at 21 kHz, -64 dB at 22 kHz.
A slow negative tail (-3.9e-4 at tap 100, time constant 71 samples) matters:
cutting the filter to 200 taps costs 8.5 dB, to 60 taps 25 dB. It is not
parametrised as sections (OPEN); no per-line difference of the filter exists
(per-line 12-tap corrections change the 44.1 kHz null by 0.00 dB).

- FITTED. Free 221-tap composite kernel, estimated by least squares from the

  to 17 kHz, -4.0 dB at 19 kHz, -14.2 dB at 20 kHz, -36 dB at 21 kHz.
- FITTED. Among eight window families a Kaiser-windowed sinc fits the

  the full model: cut-off 0.89997, half length 17.0055 internal samples, beta
  6.0061. Round-value test (0.9, 17, 6): 0.07 dB worse on the fit set, kept.
  Each converter is `0.9 sinc(0.9 u) x Kaiser(beta 6)` over 17 internal samples
  each side, u in internal samples.
- FITTED. Both converters have the same kernel. With the composite split as
  `|K|^a` and `|K|^(1-a)` the null is -43.7, -53.6, -59.9, -62.8, -60.0, -53.7,
  -43.9 dB for a = 0, 0.25, 0.4, 0.5, 0.6, 0.75, 1. The split is observable
  only because the delay moves while the kernel passes (see the table below).
- FITTED constants: input delay 26.5640 internal samples (26.5625 scores the

## What failed or stayed open

- The rule behind the sixteen start phases (section 3).
- The -71 dB floor of the core at 44.1 kHz. It is not a per-line kernel, not
  the phases (1e-7 rad) and not the position law (5e-5 samples, about -85 dB).
  The fitted centre lengths are 6.5e-5 above the integers on every line;
  float32 arithmetic of the read position is a candidate, not tested.
- Fixed filter and feedback-path kernel are measured kernels, not sections.
- A Gauss-Newton refinement of the free composite kernel inside the
  time-varying model made the null 0.8 dB worse and was dropped.
- Only six feedback pairs per group are measured. Later passes, the sign
  pattern of the full matrix and whether output taps equal loop lengths for
  lines 4 to 8 are not established.
- 44 + 44 internal samples around the lines and the two converter delays are
  known only as sums.
- Not covered: other host rates (the model needs the converter pair for each
  rate), Size, Decay (only the per-line 10^(-3 length / (T60 fs)) relation at
  0.5 s), Macro above 0.

## Macro 100 % (one realisation, 44.1 kHz host, exploratory)

filter of this packet, the L->L arrivals keep the Macro 0 spacing but lie 482
to 485 samples (10.9 ms) later (first arrival raw 1575 against 1093); each is

4 to 10 times lower; the energy of raw [0, 2400) is 2.7e-4, 6.1e-4, 1.5e-3 for
three consecutive impulses against 1.5e-2 to 1.9e-2 at Macro 0; the L->R path
is nearly empty before raw 2900; a strong slow wavelet (period about 17
samples) appears near raw 2890 to 2970. The lines and primes are therefore
the skeleton of Tide 100 %, but the kernel per arrival, the extra delay, the
levels and the cross feed are not those of this model.
