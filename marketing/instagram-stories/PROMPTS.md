# Generated background prompts

These five 9:16 artworks were generated with the built-in OpenAI image
generation tool. Typography, the Amanita Ocean name, and the actual JUCE
interface were added later by the deterministic HTML/CSS renderer, so the
generated backgrounds intentionally contain no text or product UI.

All prompts share the following campaign direction: a premium, cinematic,
dark oceanic-cosmic volume; safe negative space in the upper third; a calm
lower-middle product zone; no literal aquarium imagery, visible water surface,
fish, coral, cyberpunk HUD, sharp topographic contours, text, logos, UI, or
watermarks.

## 01 — Default

Create a premium full-bleed 9:16 vertical background for Amanita Ocean Default,
concept `PURE / OPEN`. Show an immense near-black blue-green abyss with calm,
transparent pressure rings and long, soft concentric waveforms travelling
through liquid depth. Use sparse caustic light, subtle volumetric haze, fine
particles, layered parallax, smooth gradients, and restrained cool-aqua
`#81BFC7` highlights. Keep the upper third dark for typography and create a
subtle lower-middle halo for a real plugin screenshot. Avoid hard contour lines,
literal ocean objects, generic space stars, smoke, marble, text, logos, UI, and
watermarks.

## 02 — Bloom

zone in the lower-middle. No text, logos, UI, or watermarks.
